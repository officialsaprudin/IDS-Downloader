Panduan Memasang Ekstensi di Chrome / Edge

1

Buka Halaman Ekstensi Browser

Buka Chrome dan ketik chrome://extensions atau di Microsoft Edge ketik edge://extensions di address bar.

2

Aktifkan Developer Mode (Mode Pengembang)

Nyalakan tombol toggle "Developer mode" di pojok kanan atas halaman ekstensi.

3

Klik "Load unpacked" (Muat yang belum dibongkar)

Pilih folder berikut:

D:\DATA SAPRUDIN\APLIKASI\ANTIGRAFITY\APLIKASI WINDOWS 11\idm-downloader\extension
4

Selesai! Buka YouTube

Buka sembarang video di YouTube, tombol hijau "Unduh Video Ini" akan otomatis melayang di atas video player dengan pilihan resolusi!
